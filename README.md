# Congress Stock Trades Pro

Every stock trade filed by House members, parsed from House Clerk PTR PDFs: member, state, district, ticker, buy/sell, partial, dates, amount range with midpoint. No API key. Gov data.

Run it on the Apify Store: https://apify.com/red.cars/congress-stock-trades-pro

Data page on ScraperFleet: https://scraperfleet.com/actors/congress-stock-trades-pro/

If you're comparing congress stock trades tools, this one is built for a single job and ships documented inputs and outputs. Pricing: see the listing. Full details, input schema, and FAQ on the store page.
